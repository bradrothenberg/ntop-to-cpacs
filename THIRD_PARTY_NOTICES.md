# Third-party materials

`schema/cpacs_schema.xsd` is the unmodified CPACS 3.5.1 schema from the
[official CPACS schema site](https://www.cpacs.de/schema/v3_5_1/cpacs_schema.xsd).
It is copyright 2022 Deutsches Zentrum fuer Luft- und Raumfahrt e.V. and is
licensed under the Apache License, Version 2.0. The full license is in
[licenses/CPACS-Apache-2.0.txt](licenses/CPACS-Apache-2.0.txt).

The nTop name and logo identify the software used by this example. The report
uses nTop document styles and icon assets. It uses Aeonik only when that font
is installed locally. Aeonik font files are not included. The public report can
load Inter and IBM Plex Mono from Google Fonts, with system font fallbacks.

The console bridge and saved-notebook container utilities were adapted from
the nTop Notebook API skill and GBI Rev38 development tools. Native section
sampling follows the measured GBI Rev38 extraction workflow.
